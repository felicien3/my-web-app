# My Web App

A basic Node.js web application created for RP-Kigali College, DevOps Y4 IT Practical Work 2.

## Requirements

- Node.js 14 or higher
- npm
- Git

## Run the application

1. Open a terminal in this project directory.
2. Check Node.js and npm:

   ```bash
   node --version
   npm --version
   ```

3. Start the server:

   ```bash
   node index.js
   ```

4. Open http://localhost:3000 in your browser.

You should see: **Hello, this is a basic web app!**

You can also run:

```bash
npm start
```
